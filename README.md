# ignite-2026-gold

Find the Ignite 2026 announcements that matter for your role and your company. One prompt, about five minutes, in English or Swedish. Your own Copilot reads Microsoft's Book of News and Ignite blogs and does the sorting.

**Live site:** [jw-sthlm.github.io/ignite-2026-gold](https://jw-sthlm.github.io/ignite-2026-gold/)

## What's here

| File | What it is |
|------|-----------|
| [`prompt.md`](./prompt.md) | The prompt, in English and Swedish. |
| [`ignite-2026-digest.md`](./ignite-2026-digest.md) | The 28 announcements shown on the page, in six groups, each with Microsoft's own status wording and a source link. |
| [`index.html`](./index.html) | The page GitHub Pages serves. Generated by the build script, so don't edit it by hand. |
| [`scripts/build_site.py`](./scripts/build_site.py) | Builds `index.html` from the digest and the prompt. |
| [`scripts/template.html`](./scripts/template.html) | The page template. |
| [`scripts/og.html`](./scripts/og.html) | Source for the link preview image. |
| [`assets/`](./assets/) | Fonts (Mona Sans and Cascadia Mono, both SIL OFL 1.1) and the preview image. |

## Use it

1. Copy the prompt from [`prompt.md`](./prompt.md) or the site.
2. Open Microsoft 365 Copilot Chat or Cowork, paste the prompt and send it.
3. Check the linked sources before you decide anything.

Copilot needs web search to read the Book of News. With a Microsoft 365 Copilot license, it can also use your recent mail, meetings and documents. Without one, fill in the four lines under ABOUT ME. If your Copilot can create files, as Cowork can, it also builds a deck of up to eight slides for your leadership team. Everything runs in your own Copilot.

## Update it

Statuses change. Edit the digest, and the chip and audience maps in `scripts/build_site.py` if you add or remove items. Then rebuild:

```
python scripts/build_site.py
```

The build stops if an item is missing its chips or audience, or if an em dash sneaks in.
